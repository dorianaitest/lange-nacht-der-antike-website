Anleitung für Autorinnen und Autoren

Ein neues Rätsel auf die Webseite hochladen

Mit dem kostenlosen Programm FileZilla

Mit dieser Anleitung ersetzt du das Rätselspiel auf der Webseite durch deine neue Version aus dem Editor.

Beim ersten Mal dauert das etwa 15 Minuten, weil du FileZilla installierst und die Verbindung einrichtest. Danach verbindest du dich nur noch und machst die Schritte 4 bis 7, das dauert etwa 2 Minuten.

1. Was du brauchst

Server<SERVER>
Port<PORT>
Benutzername<BENUTZERNAME>
Passwort<PASSWORT>
Zielordner/httpdocs/viewer-vorschau/current

Die rot umrandeten Werte stehen in deinen Zugangsdaten. Gib dein Passwort nie an andere weiter.

Außerdem brauchst du die neue Datei riddle.zip. Du bekommst sie im Editor über Exportieren.

Wichtig: Bewahre die letzte funktionierende Version auf. Lege jede riddle.zip, die auf der Webseite gut funktioniert hat, in einen eigenen Ordner, z. B. „Rätsel-Sicherung“. Wenn eine neue Version Fehler hat, kannst du die alte damit wieder hochladen (siehe Abschnitt 8).

Anleitung: Rätsel hochladenSeite 1 von 8
Einmalig

2. FileZilla installieren

  1. Öffne die offizielle Seite https://filezilla-project.org. Lade FileZilla nur von dort herunter, nicht von anderen Download-Seiten.
  2. Klicke auf Download FileZilla Client. Wähle die kostenlose Version FileZilla, nicht „FileZilla Pro“.

Windows

  1. Öffne die heruntergeladene Datei (sie beginnt mit FileZilla_ und endet auf .exe).
  2. Klicke dich mit Next bzw. Weiter durch die Installation.

Achtung: Zusatzangebote ablehnen. Während der Installation bietet FileZilla manchmal andere Programme an, z. B. einen Virenscanner oder Browser. Diese brauchst du nicht. Klicke in diesem Fenster auf Decline bzw. Ablehnen.

Mac

  1. Öffne die heruntergeladene Datei per Doppelklick. Es erscheint das Programm FileZilla.
  2. Ziehe FileZilla in den Ordner Programme.
  3. Beim ersten Start fragt der Mac eventuell, ob du das Programm wirklich öffnen willst. Klicke auf Öffnen.

Einmalig

3. Verbindung einrichten

Du speicherst die Verbindung einmal im Servermanager. Danach verbindest du dich mit zwei Klicks.

  1. Öffne FileZilla und klicke oben auf Datei > Servermanager.
  2. Klicke auf Neuer Server und nenne ihn z. B. „Lange Nacht der Antike Server“.
  3. Fülle im Reiter Allgemein diese Felder aus:
ProtokollFTP - File Transfer Protocol
Server<SERVER>
Port<PORT> (leer lassen, wenn in deinen Zugangsdaten kein Port steht)
VerschlüsselungWenn verfügbar, explizites FTP über TLS verwenden
VerbindungsartNormal
Benutzer<BENUTZERNAME>
Passwort<PASSWORT>

Weiter geht es auf der nächsten Seite, noch nicht auf Verbinden klicken.

Einmalig

3. Verbindung einrichten (Fortsetzung)

  1. Wechsle in den Reiter Erweitert.
  2. Trage bei Standard-Verzeichnis auf Server genau das ein:
    /httpdocs/viewer-vorschau/current
    Dann öffnet FileZilla immer direkt den richtigen Ordner.
  1. Klicke auf Verbinden.
  2. Beim ersten Verbinden erscheint das Fenster Unbekanntes Zertifikat. Setze den Haken bei Diesem Zertifikat zukünftig immer vertrauen und klicke auf OK.
    Der rote Hinweis „Hostname passt nicht zum Zertifikat“ ist bei diesem Server normal.

Beim nächsten Mal: Öffne FileZilla, klicke auf Datei > Servermanager, wähle „Lange Nacht der Antike Server“ und klicke auf Verbinden.

Jedes Mal

4. Den Ordner auf dem Server prüfen

FileZilla zeigt zwei Seiten. Links ist dein Computer (Lokal), rechts der Server (Server).

  1. Prüfe das Feld Server über der rechten Hälfte (nicht die Leiste ganz oben): Dort muss /httpdocs/viewer-vorschau/current stehen.
  2. Prüfe unten rechts in der Dateiliste: Dort muss die bisherige riddle.zip zu sehen sein.

Gelbe Ordner mit Fragezeichen sind normal. Das Fragezeichen bedeutet nur, dass FileZilla diesen Ordner noch nicht geöffnet hat. Es ist kein Fehler.

Ändere nichts außerhalb von current. Auf dem Server liegen auch andere Teile der Webseite. Verschiebe, lösche oder überschreibe dort nichts. Wenn oben rechts ein anderer Pfad steht, tippe /httpdocs/viewer-vorschau/current in das Feld und drücke Enter.

Anleitung: Rätsel hochladenSeite 5 von 8
Jedes Mal

5. Den Dateinamen prüfen

Die Datei muss genau riddle.zip heißen. Die Webseite lädt nur eine Datei mit diesem Namen.

Häufiger Fehler: Wenn schon eine riddle.zip in deinem Download-Ordner liegt, nennt der Browser die neue Datei z. B. riddle (1).zip oder riddle(2).zip. Lädst du diese hoch, ändert sich auf der Webseite nichts.

So benennst du die Datei um

  1. Falls im Ordner schon eine ältere riddle.zip liegt: Verschiebe sie zuerst in deinen Ordner „Rätsel-Sicherung“ oder lösche sie.
  2. Klicke mit der rechten Maustaste auf die neue Datei und wähle Umbenennen.
  3. Gib riddle.zip ein, ohne Leerzeichen und ohne Zahl in Klammern.

Windows: Wenn die Datei nur „riddle“ heißt

Windows blendet die Endung .zip oft aus. Dann siehst du nur riddle oder riddle (1). Schalte die Endungen im Explorer ein:

  • Windows 11: Anzeigen > Einblenden > Dateinamenerweiterungen
  • Windows 10: Reiter Ansicht > Haken bei Dateinamenerweiterungen

6. Die Datei hochladen

  1. Gehe links in FileZilla zu dem Ordner, in dem deine neue riddle.zip liegt, z. B. Downloads.
  2. Ziehe die Datei von links nach rechts in die Dateiliste des Servers. Oder: Rechtsklick auf die Datei > Hochladen.
  1. Das Fenster Zieldatei existiert bereits erscheint. Wähle Überschreiben und klicke auf OK.
  1. Prüfe ganz unten den Reiter Erfolgreiche Übertragungen. Dort muss jetzt riddle.zip stehen.
Anleitung: Rätsel hochladenSeite 7 von 8
Jedes Mal

7. Prüfen, ob das neue Spiel online ist

  1. Öffne im Browser <WEBSEITE>/viewer-vorschau/. Ist die Seite schon offen, lade sie neu (Taste F5, am Mac Cmd + R).
  2. Prüfe an etwas, das du geändert hast, z. B. am Titel des Startbildschirms, ob dein neues Rätsel zu sehen ist.
  3. Siehst du noch das alte Rätsel, öffne die Seite in einem privaten Fenster. Chrome und Edge: Strg + Umschalt + N, Firefox: Strg + Umschalt + P, am Mac Cmd statt Strg.

8. Wenn etwas nicht klappt

Problem Lösung
Auf der Webseite ist noch das alte Rätsel zu sehen. Prüfe den Dateinamen (Abschnitt 5): Rechts auf dem Server darf nur riddle.zip neu sein, keine riddle (1).zip. Prüfe den Ordner (Abschnitt 4). Teste in einem privaten Fenster.
FileZilla kann sich nicht verbinden. Vergleiche Server, Port, Benutzername und Passwort im Servermanager Zeichen für Zeichen mit deinen Zugangsdaten. Prüfe die Einstellung bei Verschlüsselung (Abschnitt 3).
Das Spiel lädt nicht oder zeigt eine Fehlermeldung. Lade die letzte funktionierende riddle.zip aus deinem Ordner „Rätsel-Sicherung“ wieder hoch, genau wie in Abschnitt 6. Damit ist das alte Spiel sofort wieder online. Prüfe danach die neue Version im Editor.
Du hast versehentlich etwas außerhalb von current verändert. Mache nichts weiter rückgängig und melde dich sofort beim Kontakt unten.

Hilfe: Wenn du nicht weiterkommst, wende dich an <KONTAKT>.
